# Typography

Use the type scale by role. Always set text with these tokens; never hard-code font family, size, line height, or tracking.

- Always set type with `--font-family`. Do not pick another face.
- Page and section titles should use `--type-h2-size`, `--type-h2-line`, and `--type-h2-tracking` together.
- Card and subsection titles should use `--type-h4-size` and `--type-h4-line`.
- Running copy should use `--type-body-size` and `--type-body-line`.
- Compact chrome (buttons, nav, helper text) should use `--type-small-size` and `--type-small-line`.
- Short labels, tags, and kickers should use `--type-label-size`, `--type-label-line`, and `--type-label-tracking` together.
- Prefer a role's size, line, and tracking as a set. Do not mix one role's size with another role's line or tracking.
